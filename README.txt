BOIKETLO GUESTHOUSE - DEMO WEBSITE

Open index.html in Chrome, Edge or Firefox.
Keep the images folder beside index.html.
All six supplied property photos are included locally and will work offline.
The optional Google Fonts and external map search require an internet connection.
The booking and WhatsApp enquiry buttons are DEMO ONLY and do not send data.
The displayed room titles are illustrative, not verified categories.

To publish on GitHub Pages, upload index.html and the images folder to a public repository, then enable Pages from the main branch root.
